# 地牢探索小游戏 · 整体介绍

一个用 **DEVFramework PCG 模块**自动生成地牢的回合制 Rogue-lite 小游戏，
展示"程序化生成 → 直接可玩"的完整闭环。运行 `res://Scenes/PCG/DungeonGame.tscn` 即可游玩。

---

## 一、玩法与目标

- **移动**：方向键逐格移动，撞墙阻挡。
- **战斗**：回合制——玩家走向怪物=攻击；每回合怪物向玩家靠近一格，相邻则攻击。
- **目标**：在地牢中拾取金币/药水/装备、清剿怪物，到达**出口**进入下一层。
- **成长**：击杀怪物获得经验升级（提升生命/攻击）；击杀掉落装备可换武器提升攻击。
- **无限挑战**：层数无限，怪物与装备强度随层数上升，每 5 层出现首领。
- **seed 可复现**：同一 seed + 同一操作路径，地牢完全一致；改 seed 即换新地牢。

## 二、核心系统

| 系统 | 规则 |
|---|---|
| **回合制战斗** | 玩家一步 = 一回合；怪物行动规则：相邻玩家→攻击，否则靠近一格 |
| **三色怪物** | 普通(蓝)/精英(紫)/首领(红)；属性 = 基础 + 层数系数；精英约 20% 概率，首领每 5 层 1 只 |
| **装备掉落** | 击杀后按怪种掉落（首领必掉/精英50%/普通25%）；词缀命名（如"锋利法杖"）+ 攻击加成；拾取替换武器 |
| **经验/等级** | 击杀加经验（普通10/精英25/首领100）；升级提升 生命+15 / 攻击+3 |
| **拾取物** | 金币(计分)/药水(+30HP)/装备(换武器)，按格拾取 |
| **多层地牢** | 到达出口进下一层；层数决定怪物/装备强度，HP/金币/等级保留 |
| **死亡结算** | HP 归零游戏结束，显示层数/金币/等级 |

## 三、地形类型（PCG 随机生成，共 4 种）

游戏从以下四种算法中**随机抽取**一张地牢地图（`GridGenDef` 配置驱动），
也可在**「地形」下拉框手动选择**某一类型（随机 / BSP 房间 / 模板拼接 / 细胞洞穴 / Prim 迷宫），方便对比各类生成效果；面板日志会显示当前类型名称、生成规则一句话与地图统计（实体/空地/连通域）。

### 1. BSP 房间地牢（Grid_BSPRooms）
- **配置**：96×96，BSP 递归深度 5，房间尺寸 5~16 格，走廊宽 2
- **规则**：二叉树递归分割地图 → 每个叶子区域生成一个随机矩形房间 → 兄弟房间用 L 型走廊连通，全部房间互通
- **特征**：规整的房间+走廊结构，像经典地牢（每个房间是空旷大厅，走廊窄窄相连）

### 2. 模板拼接地牢（Stitch_Dungeon）
- **配置**：96×96，随机放置 5 个模板（房间/大厅/宝藏室，按权重抽取），模板间距 ≥2，走廊宽 3
- **规则**：背景为墙体 → 在随机位置放置模板（挖出房间内部）→ 模板之间挖走廊连通
- **特征**：房间大小/形状不完全规整（有大厅有小房间），有"手作关卡"感

### 3. 细胞自动机洞穴（Grid_Cave）
- **配置**：96×96，初始墙占比 42%，4 轮平滑（经典 Rogue 4-5 规则）
- **规则**：随机填充 42% 墙体 → 每轮统计 8 邻域墙数 ≥4 保持墙、否则变空（平滑出连续洞穴）
- **特征**：有机的不规则洞穴网络，有宽有窄，连通性好（空连通域=1），像天然洞穴

### 4. Prim 迷宫（Grid_Maze）
- **配置**：64×64，环路度 0.1（接近完美迷宫）
- **规则**：从起点用 Prim 算法扩展生成树（隔墙打洞），环路度随机打通少量墙形成回路
- **特征**：单格宽通道的密集迷宫，几乎没有开阔区域，通道全部连通

> 所有地形统一语义：**值 1 = 墙（阻挡移动），值 0 = 地板（可走）**；
> 玩家起点选在**最大可走连通域**（避免出生被困），出口 = 离起点 BFS 最远的可走格。

## 四、技术实现

| 层面 | 说明 |
|---|---|
| **地图生成** | `PCGTool.generate_grid(def, make_rng(seed + 层数))`，四种 `GridGenDef` 随机选 |
| **种子** | `seed`(全局) + `层数` 派生每层种子，同一配置可复现 |
| **BFS 寻路** | 玩家起点/出口定位、AI 自动游玩均用 BFS（避开墙，怪格可走=主动攻击） |
| **AI 自动游玩** | 勾选「AI 自动游玩」后自动决策：相邻怪攻击 → 最近可捡物(BFS) → 出口 |
| **渲染** | `grid_to_image` 生成地图贴图 + `ColorRect` 实体标记；UI 为场景资源 |

## 五、游玩提示

- 空格/方向键移动；「AI 自动游玩」可开启自动探索观赏。
- 「重新生成地牢」或改种子即可刷新；每层重新生成（HP/金币/等级保留）。
- 优先捡装备（攻击加成明显），药水留着低血量用，精英/首领用高攻装备打更稳。
