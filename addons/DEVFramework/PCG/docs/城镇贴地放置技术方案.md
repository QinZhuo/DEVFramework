# 城镇贴地放置（地形起伏）技术方案

> 状态：**V0 + V1 已实施**（vision 验收通过；梯度分布 P50=0.017 / P95=0.224）
> 背景：现有城镇管线存在「平面假设」——`generate_town` 接收 HeightMap 且选址/主街已使用坡度代价，
> 但产出的道路/地块/建筑全部落在 y=0 平面。在有起伏的地形上，建筑悬空或半埋。

## 14. 视觉与地貌修复记录（2026-08-25）

针对「城镇建在山上 / 周边无地貌变化 / 3D 窗户飞到房顶 / 2D 斜杠背景分不清颜色」的修复：

1. **岛屿掩膜强度 bug**：`island_strength` 参数此前从未参与运算（>0 即全强度掩膜），
   修复为 `h *= lerp(1.0, falloff, strength)`；`HeightMap_Island.tres` 同步 0.7→1.0 保持原貌。
2. **山地地形水域占比过高**（约 80% 在水下，陆地太少导致城镇挤在坡上）：
   `HeightMap_Mountain.tres` 调整为 min_height=0.12 / height_curve=1.05 / island_strength=0.14 /
   ridge_weight=0.9，实测分布 水≈32% 滩≈8% 草≈33% 岩≈26% 雪≈2%（宜居草地为主体+山峦变化）。
3. **选址防贴边**：候选评分窗口（site_radius）须完整落在地图内，杜绝城镇被地图边缘截断；
   山地 5 种子实测选址平均坡度 ≤0.045、最大坡度 ≤0.115（硬阈值 0.14 内），全部落在平缓地。
4. **选址硬坡度惩罚**：`_site_score` 半径内最大坡度 >0.14 时平坦分 ×0.25，权重改为
   0.55*平坦 + 0.30*近水 + 0.15*陆地占比。
5. **2D demo**：底图改为高度伪彩（`_terrain_color`，水/滩/草/岩/雪，阈值与 3D 分层一致）；
   农田条纹按地块长边方向（告别全局对角斜杠）；新增颜色图例；修复 `city.sea_level` 笔误编译错误。
6. **3D demo**：建筑墙/地板/门/窗 Y 全部锚定切台基准 ground_y（此前用原始地形高，
   山地建筑构件整体错位"飞到房顶"）；地形柱按高度分层着色（草/岩/雪）+ 半透明海平面水体。
7. **TownLayout 序列化补全**：buildings 增加漏掉的 `ground_y` / `foundation` 字段
   （to_data/from_data 对称）。
8. **3D 表现打磨**（demo 渲染消费侧，PCG 数据不变）：坡顶建筑砖砌烟囱（按 id 确定性选角）、
   教堂钟楼（收分塔身+金色顶）、平顶屋顶附属房/水箱、门口雨棚、广场中心设施分型
   （水井=石台双柱木顶 / 喷泉=双层水池水柱 / 市集台）+ 四向彩色顶棚市场摊位、
   现代风(混凝土/玻璃幕墙)屋顶配色；新增滚轮缩放（近景查看细节）。
9. **矿镇配置调优**：Town_MountainMine.tres 显式 `flat_roof_styles=[]`（石砌保留坡顶，
   否则默认值把石砌全变平顶致烟囱语义落空）+ 街区参数加密（min_block_area=16 /
   max_block_area=400 / street_spacing 4~7），建筑数 4→91 (seed42)；PCGDemo3D 默认种子
   改 42。vision 验收：都市 7.5/10、矿镇 8/10。
10. **窗户飞天根修 + 道路铺装**（2026-08-25 MCP 调试会话）：
    - **窗户双重叠加 bug（真根因）**：`wy` 已含切台基准 gy，`wbase.y` 又赋 gy，
      相加后窗 Y = 2×gy + 层高——山地建筑窗户整体飞到房顶上方空中。平地 gy=0 时
      bug 完全隐藏（此前多轮远景验收未暴露）。修复为相对偏移 `wy = 1.15 + row*1.5`。
    - 教训：远景截图验收无法发现此类局部错位，必须近景+逐项对照；且 run_game 复用
      运行中实例时旧代码不会热重载，改码后必须 stop→run 重启再验。
    - 道路"破碎不平"：薄路面板(0.13~0.25)在格间台阶处露缝 → 加厚为半嵌入铺装层
      (主街/桥 0.9、次街 0.75、巷道 0.65)，人行道同步 0.3；City_Grid.tres 收紧
      road_max_grade=0.06、main_width=3（三格大道）。
    - 主街中线黄色虚线：逐格判定直段不可行(main_jitter 蜿蜒路纯直段仅 1 格)；
      最终沿 layout.road_edges 的 MAIN 折线撒点(天然居中)，自发光黄材质
      (强环境光下 albedo 黄会被冲白)。像素级验证通过。
11. **Arterial 横穿主干道层**（2026-08-25，业内参照 CS:Skylines 路网分级）：
    - 新增可插拔步骤 `TownArterialStep`（内置链位于 RoadStep→RingStep 之间）：
      N 条横穿全图的宽阔平直主干道（一横一纵即十字骨架），值语义
      `road_arterial_value=12`，折线写入 road_edges(cls=ARTERIAL)。
      印层不覆盖已有路值 → 与主街/环路交叉自然成路口；沿线按间距两侧生长
      集散次街(Collector)；路面梯度由 ConformStep 兜底整平；遇水自动架桥。
    - City_Grid.tres 配置：arterial_width=5(次街 2 格的 2.5 倍, 一眼可辨)、
      jitter=0.15(平直车行感)、street_spacing 放大至 10~16、街区放大
      (max_block_area=600/min=80) → "大街区+宽阔主干道"现代城区肌理。
    - 渲染：干道最深沥青色+最厚铺装；双黄实线沿折线平行撒点(±0.62)。
    - vision 验收：主干道识别/十字骨架/双黄线/穿城感全部通过，
      城区规划感 6→8 分。
12. **城区感深化**（2026-08-25 第二轮）：

## 12. V1 实施记录

- `_conform_terrain`：道路梯度约束松弛(正反扫 24 pass, 相邻路格高差强制 ≤ road_max_grade)
  → 广场均值整平 → 建筑 ground_y 切台锚点(最高优先) → 多源 BFS 羽化(terrace_blend 衰减) 回写

- **台阶路语义**：崖壁巷道处两侧建筑切台锚点冲突时保留台阶高差(MAX≈0.7 归一)，

## 2. 业内流派对比（2026 调研）

| 流派 | 代表 | 做法 | 优缺点 |
|---|---|---|---|
| **自动填挖 cut & fill** | Cities Skylines / AoE IV / Workers&Resources | 建筑/道路自动改造地形，成本计入 | 视觉统一、导航简单；地形成为生成后产物，需输出改后图 |
| **可变基础+桩基** | Foundation（部件自带可变高度基础）/ Farthest Frontier（玩家苦求 auto-flatten 未果的反例） | 每柱采样地形高、相邻允许阶梯差、桩基补空隙 | 地形不动、桥涵自然；陡坡下建筑底部悬空感靠桩基解释 |
| **样条贴合** | 道路类专用（Unity spline road） | 路面网格沿样条连续变形 | 仅适合道路，不适合建筑 |

社区共识（ZEST 建筑实践 + 游戏论坛）：**小坡切台整平、大坡桩基**是组合主流；
Foundation 上线可变基础前「半浮半埋」长期被诟病——印证纯平面假设不可行。

## 3. 方案分级

### V0 最小可行（约 1 天）——桩基流派完整版，不改地形

- `generate_town` 把 HeightMap **透传**进 `layout.heightmap`
- 建筑放置时四角采样：
  - 高差 ≤ `build_max_step`(0.08) → `foundation="terrace"`，`ground_y`=四角均值
  - 高差 > 阈值 或 平均坡度 > `build_max_slope` → `foundation="stilt"`，`ground_y`=最高角
  - 水上/超陡 → 该地块弃建（复用现有桥/坡度规则）
- 树/路灯/长椅/门/家具 y 全部取地表高（消费方 `y = h × height_scale`）
- 导航栅格按真实高度分层：可行走列 solid 填至 `round(h × nav_layers)`；墙体从地表填到墙顶
  → `NavBridgeTool.bake_navigation_3d` 找顶面的逻辑天然支持，零框架改动

**V0 解决**：视觉悬空（切台/桩基解释）、导航真地形。
**V0 不解决**：陡坡路面锯齿、建筑周边地面不平整感。

### V1 完整贴地（再 +2 天）——加入 cut & fill 回写

- 道路走廊整平：沿路径以限坡滑窗重算路面高，回写地形（挖沟填堤），两侧 `terrace_blend` 格羽化过渡
- 建筑切台回写：footprint 内强制 `ground_y`，外圈羽化
- 广场整平同理；回写限制在陆地格（防填海）
- `layout.heightmap` 输出**回写后的最终地形**，水陆判定/消费方统一用它
- 新参数（CityDef）：`terrain_conform`(总开关) / `road_max_grade` / `terrace_blend`

### V2 增强（后续可选）

- 桥墩语义、梯田式地块、等高线对齐主街、路面纵断面优化

## 4. 数据结构改动

```gdscript
# TownLayout
var heightmap: HeightMap = null        # V1 为回写后最终地形; V0 为透传原地形
# buildings 追加:
"ground_y": float      # 切台基准高(归一 0..1, 渲染方乘 height_scale)
"foundation": String   # "terrace" | "stilt"
# CityDef 追加:
build_max_step := 0.08     # 四角高差阈值(超过转桩基)
build_max_slope := 0.18    # 平均坡度弃建阈值
height_scale := 8.0        # 归一高→世界格高的换算(供 demo/参考)
```
